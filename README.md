## Что реализовано

### Бэкенд (Django REST Framework)

- **REST API** для каталога фильмов, сериалов и мультфильмов
- **JWT-аутентификация** — регистрация, вход, выход, обновление токенов
- **Фильтрация** по жанру, стране, году, типу доступа, языку и возрастному рейтингу
- **Пагинация** результатов поиска
- **Система отзывов** с оценками от 1 до 10
- **Избранное** — добавление и удаление контента
- **Профиль пользователя** с аватаром, телефоном и статусом подписки
- **Мультиязычность** — русский, кыргызский, узбекский (i18n_patterns)
- **Swagger-документация** API (доступна по `/docs/`)
- **Разграничение доступа** — VIP-контент доступен только подписчикам

### Фронтенд (React + Vite)

- **Современный SPA** с client-side роутингом (React Router)
- **Тёмная киношная тема** с элементами киноплёнки
- **Адаптивный дизайн** — корректно отображается на мобильных устройствах
- **Каталог** с карточками фильмов, сериалов и мультфильмов
- **Страницы деталей** с постером, описанием, трейлером, видеоплеером, актёрами
- **Фильтры** — жанр, страна, тип доступа, язык, возраст, диапазон годов
- **Отзывы** — просмотр, создание и удаление собственных отзывов
- **Избранное** — кнопка «В избранное» на странице контента, отдельная страница
- **Защита маршрутов** — профиль и избранное доступны только авторизованным пользователям
- **Автоматическое обновление токена** — при истечении access-токена

### Инфраструктура

- **Docker-ready** конфигурация для деплоя
- **nginx** — раздача статики и проксирование API
- **gunicorn** — WSGI-сервер для Django
- **WhiteNoise** — сжатие и кэширование статических файлов
- **CORS** — настроен для раздельного запуска фронтенда и бэкенда

## Быстрый старт (локальная разработка)

### 1. Бэкенд

```bash
cd movie
python -m venv ../venv
source ../venv/bin/activate   # Linux/Mac
# ..\venv\Scripts\activate    # Windows

pip install -r ../requirements.txt
python manage.py migrate
python manage.py runserver
```

Бэкенд доступен на `http://127.0.0.1:8000`

### 2. Фронтенд

```bash
cd frontend
npm install
npm run dev
```

Фронтенд доступен на `http://localhost:5173`

## Деплой на AWS EC2

```bash
# 1. Подключитесь к EC2
ssh -i etno-key.pem ubuntu@<EC2_IP>

# 2. Скопируйте проект
scp -i etno-key.pem -r ./Etno_Practic ubuntu@<EC2_IP>:/home/ubuntu/

# 3. Запустите скрипт настройки
cd /home/ubuntu/Etno_Practic
chmod +x deploy/setup_server.sh
./deploy/setup_server.sh

# 4. Создайте суперпользователя
cd movie && source ../venv/bin/activate
python manage.py createsuperuser
```

Подробнее: см. `deploy/setup_server.sh`
