# Деплой Etno_Practic на AWS EC2 + nginx (Free Tier)

## Архитектура деплоя

```
Пользователь (браузер)
    │
    ▼ :80
┌─────────────┐
│    nginx     │  ← раздаёт собранный React (static) + проксирует /ru/* → gunicorn
└──────┬──────┘
       │ :8000 (internal)
┌──────┴──────┐
│   gunicorn   │  ← Django WSGI, 3 воркера
└──────┬──────┘
       │
┌──────┴──────┐
│   SQLite     │  ← db.sqlite3 (для учебного проекта достаточно)
└─────────────┘
```

## Часть 1 — Подготовка кода (локально)

### Шаг 1: Добавить gunicorn и whitenoise в requirements.txt

**Файл:** `requirements.txt` (корень проекта)

Добавить:
```
gunicorn==23.0.0
whitenoise==6.9.0
```

### Шаг 2: Обновить settings.py для продакшена

**Файл:** `movie/movie/settings.py`

Изменения:
```python
# Добавить whitenoise в INSTALLED_APPS и MIDDLEWARE
INSTALLED_APPS += []  # whitenoise не нужен в apps, только middleware

MIDDLEWARE = [
    'corsheaders.middleware.CorsMiddleware',
    'django.middleware.security.SecurityMiddleware',
    'whitenoise.middleware.WhiteNoiseMiddleware',  # ← ДОБАВИТЬ сразу после SecurityMiddleware
    # ... остальные без изменений
]

# Статика
STATIC_ROOT = os.path.join(BASE_DIR, 'staticfiles')
STATIC_URL = 'static/'
STATICFILES_STORAGE = 'whitenoise.storage.CompressedManifestStaticFilesStorage'

# CORS — разрешить продакшен-домен/IP
CORS_ALLOWED_ORIGINS = [
    "http://localhost:5173",
    "http://127.0.0.1:5173",
    # EC2 public IP будет добавлен в .env на сервере
]
# Альтернатива: читать из env
# CORS_ALLOWED_ORIGINS = os.getenv('CORS_ALLOWED_ORIGINS', '').split(',')

# Безопасность для HTTPS (nginx будет терминировать SSL)
SECURE_PROXY_SSL_HEADER = ('HTTP_X_FORWARDED_PROTO', 'https')
SESSION_COOKIE_SECURE = not DEBUG
CSRF_COOKIE_SECURE = not DEBUG
```

### Шаг 3: Создать nginx конфиг

**Новый файл:** `deploy/nginx.conf`

```nginx
server {
    listen 80;
    server_name _;

    # Собранный React фронтенд
    location / {
        root /home/ubuntu/Etno_Practic/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # Django API (все запросы к /ru/* и /admin/*)
    location /ru/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /admin/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /accounts/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
    }

    location /docs/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
    }

    # Медиа-файлы (постеры, видео)
    location /media/ {
        alias /home/ubuntu/Etno_Practic/movie/media/;
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # Статика Django (admin CSS/JS)
    location /static/ {
        alias /home/ubuntu/Etno_Practic/movie/staticfiles/;
        expires 30d;
    }
}
```

### Шаг 4: Создать systemd сервис для gunicorn

**Новый файл:** `deploy/gunicorn.service`

```ini
[Unit]
Description=Etno_Practic Gunicorn
After=network.target

[Service]
User=ubuntu
Group=ubuntu
WorkingDirectory=/home/ubuntu/Etno_Practic/movie
ExecStart=/home/ubuntu/Etno_Practic/venv/bin/gunicorn \
    --workers 3 \
    --bind 127.0.0.1:8000 \
    --timeout 300 \
    movie.wsgi:application
Restart=always
Environment="DJANGO_SETTINGS_MODULE=movie.settings"

[Install]
WantedBy=multi-user.target
```

### Шаг 5: Создать скрипт деплоя

**Новый файл:** `deploy/setup_server.sh`

```bash
#!/bin/bash
set -e

echo "=== Обновление системы ==="
sudo apt update && sudo apt upgrade -y

echo "=== Установка Python 3.12, pip, venv ==="
sudo apt install -y python3.12 python3.12-venv python3-pip

echo "=== Установка Node.js 20 ==="
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

echo "=== Установка nginx ==="
sudo apt install -y nginx

echo "=== Клонирование проекта ==="
cd /home/ubuntu
git clone <REPO_URL> Etno_Practic || true
cd Etno_Practic

echo "=== Настройка Python окружения ==="
python3.12 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt

echo "=== Настройка .env для продакшена ==="
cat > movie/.env << 'EOF'
SECRET_KEY=<СГЕНЕРИРОВАТЬ_НОВЫЙ>
DEBUG=False
ALLOWED_HOSTS=<EC2_PUBLIC_IP>,localhost,127.0.0.1
EOF

echo "=== Сборка фронтенда ==="
cd frontend
npm install
echo "VITE_API_BASE_URL=http://<EC2_PUBLIC_IP>" > .env
echo "VITE_API_LANG=ru" >> .env
npm run build
cd ..

echo "=== Миграции и статика ==="
cd movie
python manage.py migrate
python manage.py createsuperuser --noinput  # настроить через env
python manage.py collectstatic --noinput
cd ..

echo "=== Настройка nginx ==="
sudo cp deploy/nginx.conf /etc/nginx/sites-available/etno
sudo ln -sf /etc/nginx/sites-available/etno /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl restart nginx

echo "=== Настройка gunicorn ==="
sudo cp deploy/gunicorn.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable gunicorn
sudo systemctl restart gunicorn

echo "=== Готово! ==="
echo "Откройте http://<EC2_PUBLIC_IP>"
```

## Часть 2 — Настройка AWS (через консоль)

### Шаг 6: Регистрация и создание EC2

1. Зайти на https://console.aws.amazon.com
2. Создать аккаунт (нужна карта, но free tier не списывает)
3. **Services → EC2 → Launch Instance:**
   - Name: `etno-practic`
   - AMI: **Ubuntu 24.04 LTS** (free tier eligible)
   - Instance type: **t2.micro** (free tier)
   - Key pair: создать новый, скачать `.pem` файл
   - Network settings:
     - Allow SSH (port 22) — My IP
     - Allow HTTP (port 80) — Anywhere
   - Storage: **30 GB gp3** (free tier)

### Шаг 7: Подключение к серверу

```bash
# Из папки где лежит .pem файл:
chmod 400 etno-key.pem
ssh -i etno-key.pem ubuntu@<EC2_PUBLIC_IP>
```

### Шаг 8: Запуск деплоя

```bash
# Скопировать проект на сервер (из локальной машины):
scp -i etno-key.pem -r ./Etno_Practic ubuntu@<EC2_PUBLIC_IP>:/home/ubuntu/

# Или клонировать из git:
# git clone <REPO_URL> Etno_Practic

# На сервере:
cd /home/ubuntu/Etno_Practic
chmod +x deploy/setup_server.sh
./deploy/setup_server.sh
```

## Важные замечания

- **SQLite** подходит для учебного проекта, но не для продакшена с высокой нагрузкой. Для масштабирования нужна будет PostgreSQL (RDS или на EC2).
- **SECRET_KEY**必须在 сервере быть новым, не тот что в `.env` локально.
- **DEBUG=False** обязательно в продакшене.
- **Медиа-файлы** хранятся локально на EC2. При перезапуске инстанса данные сохраняются (EBS volume), но при удалении инстанса — теряются. Для production нужен будет S3.
- **SSL/HTTPS** можно добавить позже через Let's Encrypt (certbot).
